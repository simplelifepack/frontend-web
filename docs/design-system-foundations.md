# Frontend foundation standardization

15 October 2026. Implemented in `/Users/ranjith/code/frontend-web` on top of its existing working-tree migration. Existing Poppins files, typography tokens, and Button variants (`primary`, `secondary`, `tertiary`, `default`) remain intact. No dependencies were added or removed in this pass.

## Inspection and ownership

Inspected the existing variables, shared controls/surfaces, theme provider, global CSS, active route imports, form compositions, chart implementation, and overlay callers before editing. A TypeScript AST traversal from `src/main.tsx` reaches 211 modules, including shared barrel exports. This is a conservative import inventory, not proof that every conditional screen was exercised.

Shared components retain the `ComponentName/index.tsx`, `styles.ts`, `types.ts` structure and typed styled-components theme. Pages retain their surrounding layout and product handlers.

## Deliberate exceptions

- **Brand/artwork:** Landing illustrations, BrandLogo, Google branding, and the package READY stamp retain their specialized appearance. They are not general UI icons or generic status components.
- **Document output:** Printed emergency/insurance cards and document/paper previews retain content-specific colors and dimensions. Printable documents require a stable paper palette.
- **Layout geometry:** Unique grid tracks, chart coordinates, timeline positions, safe-area calculations, circular geometry, unusual content widths, and one-off spacing remain local. Existing intermediate spacing/radii were not rounded merely to reduce the token count.
- **Responsive differences:** Composition-specific thresholds such as 560, 620, 640, 880, 920, and 1020 px remain local. The distinct 760 and 767 px behavior is preserved; merging those thresholds could alter navigation and page transitions.
- **Specialized icons:** Uncommon icon sizes and specialized geometry remain where they convey density or product meaning. The general library and common sizing/stroke decisions are shared.
- **Forms:** Existing compact multi-control groups keep their native labels/fieldsets and page layout. The dormant React Hook Form adapter is retained; active native forms do not require migrating to a different form controller. Native file inputs and preview range controls remain native.
- **States:** Domain-specific empty-state wording, skeleton composition, loading conditions, and validation content remain in pages. No new product flows or generic state framework were added.
- **Dormant code:** Unreachable old authentication and Gmail/Drive flows, and unused starter primitives, were not comprehensively migrated. Existing public compatibility tokens and adapters remain where referenced.
